How it works

There's no interface to click through. You talk to Claude in your terminal; everything else is text files and a REAPER that runs by itself.

You describe it

A mood, a scene, a reference, an instrument line-up. /compose …

Claude writes the plan

Key, form, chords in Roman numerals, themes in scale degrees, a role for each instrument.

The engine writes the notes

Voice leading, melodies fitted to the chords, answers and counter-lines, ostinatos, drums. The same seed gives the same notes.

REAPER plays them

On your own plug-ins, every controller and articulation set, each track rendered to its own stem.

The mix is measured

Each part's loudness is set by its role under the melody, then mastered.

# songs/black-feather/plan.yaml (excerpt), written by Claude
key: C# minor
tempo: 150
themes:
  wing: "1:3/2 5:1/2 b6:2 | 5:1 4:1 3:1 b2:1 | 1:2 r:1/2 1:1/2 3:1 | 4:3 5:1 | …"
sections:
  - name: wings
    bars: 16
    chords: "i:2 VI:2 | i | VI | iv | VI | VII | V | i | …"
    dynamics: f<ff
    parts:
      vln1:  { play: melody, line: [wing, "wing [0-16] vary=0.4", gen 4 rise end=5], octave: 5 }
      tpt:   { play: double, of: vln1, octave: -1 }
      vla:   { play: counter, against: vln1 }
      vc,cb: { play: bass, rhythm: "X.x.x.x.X.x.x.x." }
      drums: { play: drums, groove: double, cymbal: ride, fill: 4 }

Make your own

Bring your own instruments

It comes with no sounds. It plays the plug-ins you've installed, free or paid, through your own copy of REAPER, so what you hear is only as good as what you own.

  • Known out of the box: BBC Symphony Orchestra Discover (free) and EZdrummer 3.
  • Anything else, such as a Kontakt library or a synth, takes a one-time setup that Claude walks through with you.
  • macOS for now, with REAPER 7, Node 22.18+ and ffmpeg.

Get started

# once
git clone https://github.com/endel/claude-soundtrack-composer
cd claude-soundtrack-composer
npm install
npm run doctor

# then, in Claude Code
/compose an urgent chase cue for strings and drums
